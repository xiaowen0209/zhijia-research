Transformer

注意力机制
📐 算法进阶

一种基于自注意力机制的深度学习架构，能捕获序列中任意位置间的依赖关系

端到端

End-to-End

从传感器原始输入到车辆控制输出，用一个大模型直接映射，省去传统模块化流水线

Occupancy Network

占据网络

将3D空间划分为体素网格，预测每个体素是否被占据，实现对任意形状障碍物的检测

激光雷达

LiDAR

4D Imaging Radar

摄像头

Camera

智驾最基础的传感器，通过图像捕捉环境信息，成本最低但受光照和天气影响

多传感器融合

Sensor Fusion
👁 感知进阶

将摄像头、激光雷达、毫米波雷达等多种传感器数据整合，形成更完整可靠的环境感知

VLM

Vision Language Model

能同时理解图像和文本的多模态大模型，让智驾系统具备"常识推理"能力

LLM

Large Language Model
📐 算法进阶

基于Transformer的大规模语言模型，在智驾中用于场景理解、交互和知识推理

TOPS

NVIDIA Orin

Orin-X

NVIDIA Thor

Thor

征程6

图灵AI芯片

小鹏图灵

HSD

Horizon SuperDrive

模仿学习

Imitation Learning
📐 算法进阶

让AI模型通过学习人类驾驶数据来模仿人类驾驶行为，是端到端智驾的核心训练方法

强化学习

Reinforcement Learning
📐 算法专家

通过试错和奖励信号让模型学习最优策略，在智驾中用于解决模仿学习无法覆盖的场景

NOA

Navigate on Autopilot
🏗 架构入门

导航辅助驾驶的总称，车辆可在导航路线指引下自动完成变道、上下匝道等操作

L3级自动驾驶

L3
⚖ 法规进阶

在特定条件下系统完全负责驾驶，驾驶员可脱手脱眼，系统无法处理时需驾驶员接管

ODD

Operational Design Domain
⚖ 法规进阶

定义自动驾驶系统可以正常运行的条件范围（道路类型、天气、速度等），超出ODD系统必须退出

接管请求

Take-over Request
⚖ 法规进阶

L3系统在无法继续自动驾驶时向驾驶员发出的接管请求，驾驶员必须在限定时间内接管

DMS

Driver Monitoring System
📡 传感器入门

通过车内摄像头监测驾驶员状态（疲劳/分心），是L3自动驾驶的安全保障组件

扩散模型

Diffusion Model
📐 算法专家

通过逐步去噪生成数据的生成式模型，在智驾中用于轨迹生成和多模态规划

功能安全

Functional Safety
⚖ 法规专家

确保汽车电子系统在故障时仍能安全运行的标准体系，ASIL-D是最高安全等级

世界模型

World Model
📐 算法专家

对物理世界进行内部建模和预测的系统，让智驾具备'想象'和'预判'能力

自动紧急制动

AEB
📊 评测入门

车辆检测到前方碰撞风险时自动刹车的安全系统，是ADAS最基础也是最重要的功能之一。

前向碰撞预警

FCW
📊 评测入门

检测到与前车/障碍物存在碰撞风险时发出声光警告，比AEB更早介入的预警系统。

接管率

Disengagement Rate
📊 评测进阶

自动驾驶系统运行中需要人类驾驶员接管控制的频率，是衡量系统成熟度的核心指标。

影子模式

Shadow Mode
📊 评测进阶

系统在后台静默运行自动驾驶算法但不行使控制权，对比算法决策与人类驾驶员操作来发现差异和改进点。

仿真测试

Simulation
📊 评测进阶

在虚拟环境中模拟自动驾驶系统运行，用于大规模回归测试和长尾场景验证，是实车测试的必要补充。

预期功能安全

SOTIF
📊 评测专家

解决自动驾驶系统在无故障情况下因功能局限（如恶劣天气、传感器盲区）导致的安全问题，区别于传统功能安全。

汽车安全完整性等级

ASIL
📊 评测进阶

ISO 26262定义的汽车功能安全等级，从A到D递增，D级最严格。自动驾驶核心功能通常要求ASIL-D。

功能安全

FuSa
📊 评测进阶

确保汽车电子电气系统在故障时不产生不可接受的风险，ISO 26262是核心标准。

运行设计域

ODD
📊 评测进阶

自动驾驶系统被设计能在其中正常运行的环境条件范围，包括道路类型、天气、速度等限制。

软件在环测试

SIL
📊 评测进阶

将自动驾驶软件代码编译后在PC上运行，配合仿真环境进行测试验证，是V模型开发流程中的关键环节。

新车评价规程

NCAP
📊 评测入门

独立第三方对新车安全性能进行评级测试的规程，近年大幅增加ADAS/智驾相关测试项目。

车道偏离预警

LDW
📊 评测入门

车辆在未打转向灯的情况下偏离当前车道时发出警告，是L2级ADAS的基础功能。

车道保持辅助

LKA
📊 评测入门

在车辆偏离车道时自动施加轻微转向力将车辆拉回车道内，是L2级辅助驾驶的核心功能之一。

自适应巡航控制

ACC
📊 评测入门

根据前车速度自动调整本车速度和车距的巡航系统，是L2级辅助驾驶最基本的功能。

交通拥堵辅助

TJA
📊 评测入门

在低速拥堵场景下自动控制车辆跟车和保持在车道内行驶的L2级功能，是ACC+LCC在拥堵场景的特化版本。

集成式巡航辅助

ICA
📊 评测入门

在结构化道路（高速/城市快速路）上自动控制车速、车距和车道居中的L2功能，是TJA的高速版。

模型预测控制

MPC
📊 评测专家

通过在有限时域内优化未来控制序列的算法，广泛用于自动驾驶的轨迹规划和控制层。

PNC

Planning and Control
🧠 决策进阶

规划与控制的合称，智驾系统从感知到执行的核心环节

行为规划

Behavior Planning
🧠 决策进阶

决定车辆应采取的宏观驾驶行为，如跟车、换道、超车、让行等

轨迹规划

Trajectory Planning
🧠 决策进阶

生成满足行为决策的具体行驶轨迹，包括位置、速度、加速度的时间序列

任务规划

Task Planning
🧠 决策入门

根据导航目的地规划全局行驶路线，类似于导航软件的路线规划

预测

Prediction
🧠 决策进阶

预测其他交通参与者(车辆/行人/骑行者)的未来运动轨迹和行为意图

ODD

Operational Design Domain
🧠 决策进阶

自动驾驶系统设计时定义的正常运行条件范围，超出则需人类接管

横向控制

Lateral Control
🎯 控制进阶

控制车辆方向盘转角，实现车道保持、变道、转弯等横向运动

纵向控制

Longitudinal Control
🎯 控制进阶

控制车辆油门和刹车，实现跟车、定速、减速停车等纵向运动

横纵耦合控制

Coupled Control
🎯 控制专家

复杂场景下横向和纵向控制的协同优化，如弯道减速、变道加速

PID控制

PID Control
🎯 控制入门

工业界最经典的闭环控制算法，通过比例、积分、微分三个环节消除误差

GNSS

Global Navigation Satellite System
📍 定位入门

通过接收多颗卫星信号计算车辆位置的定位系统，RTK技术可达厘米级精度

INS

Inertial Navigation System
📍 定位进阶

通过加速度计和陀螺仪积分推算车辆位置和姿态，不依赖外部信号

高精地图

HD Map
📍 定位进阶

厘米级精度的道路信息地图，包含车道线、交通标志、曲率等丰富语义信息

SD地图

Standard Definition Map
📍 定位入门

传统导航地图，精度在米级，用于日常路线规划，不参与车道级定位和决策

多源融合定位

Multi-source Fusion Localization
📍 定位进阶

融合GNSS、惯导、视觉、激光雷达、高精地图等多种定位源的综合定位方案

V2X

Vehicle to Everything
📶 通信进阶

车辆与周围环境进行信息交换的技术体系，突破单车感知局限实现超视距信息获取

GOD

General Obstacle Detection
🏗 架构进阶

不预设障碍物类别，直接判断区域是否可通行的检测方法

Override

接管
📊 评测入门

驾驶员主动干预自动驾驶系统的控制行为，是评价系统可靠性的核心指标

SR

Situation Recognition
👤 人机入门

将传感器处理后的信息渲染为可视化界面，让用户看到'系统看到了什么'

HMI

Human-Machine Interface
👤 人机入门

智驾系统与驾驶员之间的信息交换界面，包括仪表盘、中控屏、HUD、声音、震动

数据闭环

Data Loop
🛠 开发进阶

持续的数据采集→分析→优化→验证循环，是自动驾驶算法迭代的核心方法论

仿真测试

Simulation
🛠 开发进阶

在虚拟环境中模拟各种驾驶场景进行算法验证，是内场测试的核心手段

SIL

Software-in-the-Loop
🛠 开发进阶

在纯软件环境中运行算法代码进行验证，是内场测试链的基础环节

HIL

Hardware-in-the-Loop
🛠 开发进阶

在仿真环境中接入真实硬件(域控制器)进行闭环测试，验证软硬件集成效果

通勤路线

Commuting Route
🛠 开发入门

用户日常上下班的固定重复路线，是量产用户最主要行驶场景和数据采集主力

MCAP

Message Container Archive Packet
🛠 开发进阶

路测数据的标准存储格式，支持多通道时序数据(图像/点云/雷达等)

ROS

Robot Operating System
🛠 开发进阶

机器人软件开发的核心框架，自动驾驶开发中被广泛采用

Foxglove

Foxglove Studio
🛠 开发进阶

现代化的机器人数据可视化平台，支持数据回放、可视化分析和调试

RViz

rviz
🛠 开发进阶

ROS官方三维可视化工具，实时显示传感器数据、规划轨迹等调试信息

MPI

Miles Per Intervention
📊 评测入门

总行驶里程除以接管次数，衡量智驾系统持续运行能力的核心指标

MCP

Miles Per Intervention Coverage
📊 评测进阶

接管事件发生的路段占总里程的比例，可识别系统能力的薄弱环节

接管请求

Takeover Request
👤 人机进阶

L3级别系统在即将超出ODD时向驾驶员发出接管请求的安全机制

传感器融合

Sensor Fusion
👁 感知进阶

整合多种传感器信息的技术，分为前融合(数据层)和后融合(目标层)

VRU

Vulnerable Road User
👁 感知入门

包括行人、自行车骑行者等无保护、行为随机、目标小的道路使用者

长尾场景

Corner Case
📊 评测进阶

发生概率低但种类众多的极端驾驶场景，是智驾系统最难覆盖的部分

白名单

White List
🏗 架构入门

经过验证的可信障碍物类别列表，与GOD互补提高识别效率和准确性

域控制器

Domain Controller
🏗 架构入门

车载计算核心，集中处理感知/规划/控制等计算任务的硬件平台

触发机制

Trigger Mechanism
🏗 架构进阶

智驾功能策略介入的条件判断逻辑，定义系统何时激活/退出/提醒接管

行为规划

Behavior Planning
🧠 决策进阶

决定车辆应采取的宏观行为（跟车/换道/超车/让行/停车等），是感知到控制的关键决策层。

轨迹规划

Trajectory Planning
🧠 决策进阶

生成满足行为决策的详细行驶轨迹（位置/速度/加速度随时间变化的曲线），是行为规划到运动控制的桥梁。

运动控制

Motion Control
🎯 控制进阶

将规划轨迹转化为具体的车辆控制指令（方向盘转角/油门开度/刹车力度），直接与车辆执行器交互。

规划与控制 (PNC)

Planning and Control
🧠 决策入门

规划(Planning)与控制(Control)的合称，规划生成路径，控制执行路径，是智驾系统的核心模块。

横向控制

Lateral Control
🎯 控制入门

控制方向盘转角，实现车道保持、变道、转弯等横向运动，是智驾控制的核心维度之一。

纵向控制

Longitudinal Control
🎯 控制入门

控制油门和刹车，实现跟车、定速、加减速等纵向运动，是智驾控制的另一核心维度。

有限状态机

Finite State Machine
🧠 决策入门

行为规划的经典实现方式，通过定义有限个状态和状态间的转换条件来决策车辆行为。

模型预测控制 (MPC)

Model Predictive Control
🎯 控制专家

通过建立车辆动力学模型，在每个时刻求解未来有限时域内的最优控制序列，取第一个控制量执行，滚动推进。

快速随机树 (RRT)

Rapidly-exploring Random Tree
🧠 决策进阶

基于随机采样的路径规划算法，通过在配置空间中随机生长树结构来搜索可行路径，适合高维空间。

混合A*算法

Hybrid A*
🧠 决策进阶

结合A*搜索与车辆运动学约束的路径规划算法，生成的路径满足车辆最小转弯半径等物理约束。

PID控制

Proportional-Integral-Derivative
🎯 控制入门

最经典的反馈控制算法，通过比例(P)、积分(I)、微分(D)三个环节的组合来消除误差，广泛用于纵向控制和横向控制。

全球导航卫星系统 (GNSS)

Global Navigation Satellite System
📍 定位入门

通过接收多颗卫星信号计算接收机位置，结合RTK差分定位技术可达厘米级精度，是智驾定位的基础。

实时动态差分 (RTK)

Real-Time Kinematic
📍 定位进阶

通过基准站与移动站的差分修正，将GNSS定位精度从米级提升至厘米级，是高精定位的关键技术。

惯性导航系统 (INS)

Inertial Navigation System
📍 定位进阶

通过积分加速度计和陀螺仪数据推算位置和姿态，不依赖外部信号，是GNSS定位的重要补充。

惯性测量单元 (IMU)

Inertial Measurement Unit
📡 传感器入门

包含三轴加速度计和三轴陀螺仪的传感器，测量线加速度和角速度，是惯导系统(INS)的核心传感器。

高精地图 (HD Map)

High Definition Map
📍 定位入门

精度达厘米级的道路信息地图，包含车道线、交通标志、曲率等丰富语义，为定位、规划、感知提供先验信息。

标准地图 (SD Map)

Standard Definition Map
📍 定位入门

传统导航地图，精度通常在米级，用于日常导航，不参与车道级精确定位和决策。

车联网通信 (V2X)

Vehicle to Everything
📶 通信进阶

车辆与周围环境进行信息交换的技术体系，突破单车感知局限，实现超视距信息获取。

蜂窝车联网 (C-V2X)

Cellular V2X
📶 通信进阶

基于蜂窝移动通信技术的V2X方案，中国主推路线，支持直连通信(PC5)和网络通信(Uu)两种模式。

数据闭环

Data Loop

Motion Control
🎯 控制进阶

将规划轨迹转化为具体控制指令（方向盘转角/油门/刹车），直接与车辆执行器交互。

PID控制

PID
🎯 控制入门

最经典的反馈控制算法，通过比例、积分、微分三个环节消除误差，简单可靠但难以处理复杂非线性系统。

有限状态机

FSM
🧠 决策入门

一种行为建模方法，将驾驶行为定义为有限个状态及状态间的转移条件，经典的行为规划实现方式。

模型预测控制

MPC
🎯 控制专家

基于系统模型在未来有限时域内求解最优控制序列的方法，能显式处理约束，是现代智驾控制的主流方法。

驾驶员接管

Override
📊 评测进阶

驾驶员主动干预自动驾驶系统控制（踩油门/刹车/转方向盘），是衡量系统可靠性的核心指标。

数据闭环

Data Loop
🛠 开发进阶

通过持续的数据采集→分析→优化→验证循环，驱动自动驾驶算法迭代提升的核心方法论。

通用障碍物检测

GOD
👁 感知进阶

不预设障碍物类别，直接判断该区域是否可通行的感知方法，是解决"长尾场景"的关键技术。

占据栅格网络

Occupancy Network
📐 算法专家

将3D空间划分为体素网格并预测每个体素是否被占据的感知方法，是GOD通用障碍物检测的技术基础。

态势感知显示

SR
👤 人机入门

将传感器处理后的信息渲染到中控屏/仪表盘，让用户看到"系统看到了什么"，增强信任感。

通勤路线

Commuting Route
📊 评测入门

用户日常上下班的固定重复路线，路况稳定场景固定，是外场数据采集主要来源和用户感知最强的场景。

内场与外场

内场外场
🛠 开发进阶

内场=实验室可控环境测试（仿真/回灌/HIL），外场=真实开放道路测试，二者配合驱动算法迭代。

长尾场景

Long Tail
📊 评测进阶

发生概率低但种类繁多的极端驾驶场景，是自动驾驶能力的天花板，也是数据闭环要解决的核心问题。

车联网通信

V2X
📶 通信进阶

车辆与周围环境进行信息交换的技术（V2V/V2I/V2P/V2N），突破单车感知局限，实现超视距信息获取。

横纵向控制

横向控制
🎯 控制入门

横向控制管方向（方向盘/车道保持），纵向控制管速度（油门刹车/跟车），横纵耦合是复杂场景的难点。
